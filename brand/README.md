# Pixelpoint identity

Production marks for Pixelpoint Studio. Rebuild with:

```bash
python3 brand/scripts/build_wordmarks.py
```

| File | Use |
|---|---|
| `wordmark.svg` | Primary mixed-case, transparent, carbon letters |
| `wordmark-inverse.svg` | Mixed-case on dark surfaces |
| `wordmark-caps.svg` | Campaign / jersey |
| `wordmark-mono.svg` | One-color print |
| `lockup.svg` | Pixelpoint + STUDIO |
| `monogram.svg` | Notched pixel (Point on transparent) |
| `app-icon.svg` | 512 notched pixel on carbon |
| `favicon.svg` | Two-square pair, survives 16px |
| `brand-board.html` | Identity book |
| `tokens.css` | CSS variables |

Anybody instances in `fonts/` are OFL. The logo is the outlined SVG, not the font.
