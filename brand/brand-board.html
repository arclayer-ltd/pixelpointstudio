STUDIO

Rules

Hold the line.

Do

  • Carbon lettering, Point squares, nothing else in the mark.
  • One Point CTA per view, square corners.
  • Clear space: one cap-height around the wordmark.
  • Favicon = two-square pair. App icon = notched pixel.
  • Campaign type can be huge. UI type stays quiet.

Don’t

  • Don’t set the logo in Arial, Inter, or live text.
  • Don’t bring back #bad530, blue, purple, or glow blobs.
  • Don’t round the squares. Don’t pill the buttons.
  • Don’t tittle the second I of PIXELPOINT.
  • Don’t copy Nike, On, Linear, or Metalab.
