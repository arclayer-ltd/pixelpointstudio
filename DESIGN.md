# OwnerShot Ads design system

Identity stays Pixelpoint: carbon lettering, bone paper, one Point-green square used like a period. Not purple Canva, not teal CapCut, not Shopify admin blue.

## Study, then transform

| Neighbor | Steal the job, not the skin |
| --- | --- |
| Photoroom | Product is the hero. Tool chips before chrome. |
| Canva Magic Media / Dream Lab | One prompt, one generate, style as a comparison grid of the *same* subject. |
| Shopify seller | Title, description, category, price as a tight stack. Save disabled until title exists. |
| Whatnot | Cover vs extra photos. Camera grid. Required asterisks. |
| Alta | Confirm / reject / regenerate on the result, not in a chat thread. |
| CapCut | Export progress on the preview itself. Share sheet after the file exists. |

## Never copy

Layouts, icons, purple CTAs, yellow Publish pills, Dream Lab gradients, CapCut teal, Shopify grouped-list chrome, or any Mobbin frame as a shipped screen.

## Motion (ideas only)

- Capture: shutter settles, cover tile snaps to slot 1
- Generate: Point square pulses on the still, not a rainbow spinner
- Result: still crossfades into the 12s clip
- Export: preview frame border fills as progress (CapCut lesson, our color)

## Radius and type

Squared controls (2px). No 24px pills. Anybody for display and buttons. Red Hat Text for fields and body.

See `docs/ownershot-ads-design-deck.pdf` for the compact mood board and flows.
